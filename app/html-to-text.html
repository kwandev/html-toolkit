HTML to Text

Tags come off, text stays — including whatever sits inside <script> and <style>. Tick Drop code to throw those away too. Parsed with the browser's own HTML parser, so broken markup is repaired and entities (&amp;, &#12345;) are decoded. The parsed document is inert — scripts never run and no image or font request ever leaves your browser.

태그만 걷어내고 텍스트는 모두 남깁니다 — <script>·<style> 안의 코드까지. 그것까지 버리려면 Drop code를 켜세요. 브라우저 HTML 파서를 그대로 쓰기 때문에 깨진 태그도 복구되고 엔티티도 디코딩됩니다. 파싱된 문서는 비활성(inert) — 스크립트가 실행되지 않고 이미지·폰트 요청도 밖으로 나가지 않습니다. Compact를 켜면 줄바꿈 없이 공백으로만 이어 붙인 한 줄이 됩니다.
